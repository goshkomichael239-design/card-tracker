# Установка на телефон и APK

Приложение собирается в обычную статическую папку `dist/` и работает без сервера
и без сети: все файлы (страница, шрифты, картинки, звуки, иконки) лежат в ней, а
`sw.js` кладёт их в кэш браузера при первом открытии.

## Что уже есть

- **Манифест** `public/manifest.webmanifest`: имя «Карточки», иконки 192 / 512 и
  «маскируемая» иконка для Android, режим `standalone`, зелёная тема.
- **Иконки** `public/icons/` (исходник рисуется скриптом, при смене дизайна
  перегенерируются).
- **Автономная работа** `sw.js` создаётся при сборке (`vite.config.ts`): в нём
  список всех файлов сборки, кэш получает имя по этому списку, новая версия
  ждёт закрытия старых окон и не ломает открытую страницу.
- **Относительные пути** (`base: './'`): сборку можно положить в любую папку или
  на GitHub Pages в подпапку `/имя-репозитория/`, ничего не меняя.
- **Данные** лежат в IndexedDB браузера (не в папке сборки) и защищены
  запросом «постоянного хранилища».

## Проверить сборку локально

```
npm run build
npm run preview -- --host 127.0.0.1 --port 4174
```

Открыть `http://127.0.0.1:4174/` в Chrome (на `localhost` и `127.0.0.1` работает
автономный режим). После первого открытия в DevTools → Application должен быть
активный service worker и кэш `card-tracker-…`.

## GitHub Pages (позже)

Собрать `dist/` и выложить содержимое как есть (например в ветку `gh-pages`).
Установка на телефон: открыть адрес в Chrome → «Установить приложение». Для
установки и автономной работы нужен HTTPS; у GitHub Pages он есть.

## APK без хостинга (Capacitor)

Нужны Node, Android Studio и JDK. Один раз:

```
npm i @capacitor/core @capacitor/cli @capacitor/android
npx cap init Карточки ru.example.cards --web-dir=dist
npm run build
npx cap add android
npx cap sync
npx cap open android      # соберётся в Android Studio: Build → Build APK
```

Дальше после каждой правки: `npm run build && npx cap sync`.

Приложение внутри оболочки работает из локальных файлов, поэтому сервер не
нужен. Вибрация (`navigator.vibrate`) в WebView работает, звуки включаются после
первого касания.

Что стоит сделать при упаковке: заменить иконку на свою в `android/app/src/main/res`,
выбрать id пакета и версию, решить про «статус-бар» (цвет под сукно).
