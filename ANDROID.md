# Установка на телефон и APK

Приложение собирается в обычную статическую папку `dist/` и работает без сервера
и без сети: все файлы (страница, шрифты, картинки, звуки, иконки) лежат в ней, а
`sw.js` кладёт их в кэш браузера при первом открытии.

## Что уже есть

- **Манифест** `public/manifest.webmanifest`: имя «Card Tracker», иконки 192 / 512 и
  «маскируемая» иконка для Android, режим `standalone`, зелёная тема.
- **Иконки** `public/icons/` (сайт) и `tools/android-icons/res` (значок приложения на
  Android: сборка APK подставляет их вместо стандартного). Рисуются из материалов
  приложения и перегенерируются при смене дизайна.
- **Автономная работа** `sw.js` создаётся при сборке (`vite.config.ts`): в нём
  список всех файлов сборки, кэш получает имя по этому списку, новая версия
  ждёт закрытия старых окон и не ломает открытую страницу.
- **Относительные пути** (`base: './'`): сборку можно положить в любую папку или
  на GitHub Pages в подпапку `/имя-репозитория/`, ничего не меняя.
- **Данные** лежат в IndexedDB браузера (не в папке сборки) и защищены
  запросом «постоянного хранилища».

## Проверить сборку локально

```
npm run build
npm run preview -- --host 127.0.0.1 --port 4174
```

Открыть `http://127.0.0.1:4174/` в Chrome (на `localhost` и `127.0.0.1` работает
автономный режим). После первого открытия в DevTools → Application должен быть
активный service worker и кэш `card-tracker-…`.

## GitHub Pages (позже)

Собрать `dist/` и выложить содержимое как есть (например в ветку `gh-pages`).
Установка на телефон: открыть адрес в Chrome → «Установить приложение». Для
установки и автономной работы нужен HTTPS; у GitHub Pages он есть.

## APK без хостинга (Capacitor): одним файлом

Один раз поставить (вручную):

1. **Node.js LTS**: https://nodejs.org (всё по умолчанию, папка `C:\Program Files\nodejs`).
2. **Android Studio**: https://developer.android.com/studio . Папку можно оставить
   по умолчанию или поставить на другой диск. При первом запуске мастер скачает
   Android SDK (Standard). В SDK Manager → SDK Tools должны стоять «Android SDK
   Build-Tools» (нужны для подписи) и «Command-line Tools».
3. **JDK 21** (Temurin): https://adoptium.net/temurin/releases/?version=21 , с папкой
   по умолчанию. JDK Android Studio (25) для Gradle пока слишком новый.

Дальше двойной клик по `tools\build-apk.bat`: он найдёт Node, SDK и JDK, поставит
Capacitor, соберёт приложение, создаст проект Android и соберёт APK. Готовый файл:
`Card-Tracker.apk` в папке проекта. Первый запуск долгий (скачивается Gradle и
части SDK), следующие быстрые.

## Подпись APK своим ключом

Отладочная сборка подписана ключом, который Android Studio сделал на этом компьютере:
Android и Google Play Protect доверяют такой сборке меньше всего, а у сборки на другом
компьютере (или на GitHub) ключ другой, поэтому поверх неё она не установится. Поэтому
настоящий APK подписывают **своим постоянным ключом**.

- Ключ лежит **вне проекта**: `%USERPROFILE%\card-tracker-signing` (файл
  `card-tracker-release.jks` и пароль `card-tracker-release.pass`). Другая папка задаётся
  переменной `CARD_TRACKER_SIGNING_DIR`.
- **Сохраните копию обоих файлов в надёжном месте** (флешка, менеджер паролей). Потеряете
  ключ, и обновить приложение так, чтобы оно встало поверх старого, будет нельзя:
  придётся удалять и терять карточки. Не кладите их в проект и на GitHub.
- `tools\build-apk.bat` сам находит ключ: если он есть, собирает релизную сборку
  (`assembleRelease`), выравнивает (zipalign), подписывает (apksigner) и печатает
  отпечаток сертификата (SHA-256). Он должен быть **одним и тем же** при каждой сборке.
  Если ключа нет, соберётся отладочный APK и будет предупреждение.
- Подписанный APK прикладывают к релизу на GitHub вручную (Releases → Draft a new
  release → тег `v0.1.0` → перетащить файл). Сборка на GitHub по тегу тоже умеет
  подписывать, если в Settings → Secrets and variables → Actions добавить секреты
  `KEYSTORE_BASE64` (файл ключа, закодированный base64) и `KEYSTORE_PASSWORD`; без них
  она соберёт отладочный APK.

Подпись не убирает предупреждение Google Play Protect полностью: приложение не из
магазина, и Android об этом скажет. Но у подписанного своим ключом APK оно мягче, а
обновления ставятся поверх. Самый спокойный способ для пользователей: установить веб-версию
как приложение из браузера (в README).

На телефоне: перенести APK (кабель, Telegram, диск), открыть, разрешить установку из
этого источника.

Вручную то же самое делается так (если нужно):

```
npm i @capacitor/core @capacitor/android
npm i -D @capacitor/cli
npm run build
npx cap add android
npx cap sync android
cd android && gradlew.bat assembleDebug
```

Приложение внутри оболочки работает из локальных файлов, поэтому сервер не
нужен. Вибрация и локальные уведомления работают через Capacitor, звуки включаются
после первого касания. Значок приложения берётся из `tools/android-icons/res`.
Что стоит сделать позже: выбрать id пакета (сейчас `app.cardtracker`), решить про
«статус-бар» (цвет под сукно).
